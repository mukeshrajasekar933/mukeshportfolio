# Mukesh R — Full Stack Developer Portfolio

A monochrome editorial developer portfolio website built for **Mukesh R**, Full Stack Developer & AR/VR 3D Artist.

## Tech Stack

- **Framework**: Next.js 15+ (App Router)
- **Language**: TypeScript
- **Styling**: Advanced Vanilla CSS, CSS Modules, CSS custom properties, clamp sizing, blend modes
- **Animation**: GSAP 3, ScrollTrigger, QuickTo mouse physics, magnetic buttons
- **Icons**: Lucide React
- **Typography**: Space Grotesk & Inter

## Features

- **Editorial Hero**: Oversized typography centerpiece with mouse parallax and kinetic entry animations.
- **Context Cursor**: Lag-free custom cursor with interactive hover badges and magnetic button attraction.
- **Tech Stack Marquee**: Infinite velocity-responsive horizontal marquee with interactive tool inspector.
- **Signature Projects**: Immersive full-screen showcases with deep-dive modals detailing architecture and capabilities.
- **Development Process & Capabilities**: 5-step workflow and expandable service drawers.
- **Direct Contact**: Interactive inquiry modal and one-click email/phone copying.

## Getting Started

First, install the dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Build for Production

```bash
npm run build
npm start
```
